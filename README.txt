OMAR AYMAN OMAR — PORTFOLIO
============================

Files
-----
- index.html       Main portfolio page
- get-vs-post.html GET vs POST course task
- styles.css       Shared responsive design and styling

Run locally
-----------
1. Extract the ZIP file.
2. Keep all three files in the same folder.
3. Double-click index.html to open it in a browser.
4. Click "GET vs POST Task" to open the task page.

Publish online with GitHub Pages
--------------------------------
1. Sign in or create an account at https://github.com/
2. Create a new public repository, for example: omar-portfolio
3. Upload index.html, get-vs-post.html, and styles.css to the repository's root.
4. Open the repository's Settings > Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select the main branch and /(root), then save.
7. Wait for GitHub Pages to publish the site. The Pages section will show your website URL.
8. Open the URL and test both pages and all links before sending it to your instructor.

Notes
-----
- This is a static HTML/CSS project and does not need a build step.
- The GET vs POST page is an educational explanation. Its sample form snippets demonstrate syntax and are not connected to a backend server.
- For an actual POST form submission, a server-side endpoint or form service is needed.
