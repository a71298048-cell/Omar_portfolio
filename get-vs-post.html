GET vs POST

Understanding two common HTTP methods used to send requests between a browser and a web server.

✦ By Omar Ayman OmarHTML & CSSLearning notes
i
The key idea

GET is mainly used to retrieve data. POST is commonly used to submit data for processing or to create/update a resource.

01 / OVERVIEW

What are HTTP methods?

HTTP methods tell a web server what action a client (such as a browser) wants to perform on a resource. GET and POST are two of the most frequently used methods when working with websites and HTML forms.

GETRETRIEVE DATA

Request information

GET asks the server to return a resource or information. Search pages and filters often use GET, and submitted values may appear in the URL query string.

  • Parameters can appear in the URL.
  • Can be bookmarked and shared as a link.
  • Should not be used for actions that change server data.
EXAMPLE URL/search?q=html
POSTSUBMIT DATA

Send information

POST sends submitted data in the request body. It is commonly used for contact forms, sign-ups, and creating a new record on a server.

  • Form data is normally sent in the request body.
  • Not automatically represented as a shareable URL.
  • Can cause changes on the server, depending on the endpoint.
EXAMPLE REQUESTPOST /contact

02 / COMPARISON

GET vs POST at a glance

FeatureGETPOST
Typical purposeRetrieve informationSubmit data for processing
Where data is sentOften in the URL query stringUsually in the request body
BookmarkingURL can often be bookmarkedSubmitted body is not saved in a URL bookmark
Browser historyQuery string may be visible in historyForm body is not normally stored in the URL history
Data sizeURL length limits applyRequest-body size depends on server configuration
SecurityHTTPS is important when data is transmittedHTTPS is also required to protect data in transit
Common exampleSearch and filteringContact form or account creation

Important: POST is not automatically secure, and GET is not automatically insecure. Use HTTPS for both. Do not put passwords or sensitive information in a URL.

03 / HTML EXAMPLES

How are they used in HTML?

The method attribute on a form specifies how the browser sends the form data. These are example snippets for learning; they are not connected to a live server.

GET formSEARCH
<form action="/search" method="get">
  <label for="query">Search:</label>
  <input id="query" name="q" type="text">
  <button type="submit">Search</button>
</form>
A search for “HTML” could produce a URL like /search?q=HTML.
POST formCONTACT
<form action="/contact" method="post">
  <label for="email">Email:</label>
  <input id="email" name="email" type="email">
  <label for="message">Message:</label>
  <textarea id="message" name="message"></textarea>
  <button type="submit">Send message</button>
</form>
The browser sends the form fields in the request body. A server must be configured to handle /contact.

04 / CONCLUSION

When should you use each method?

01

Choose GET

When you need to request or search for information and it is useful for the URL to represent the query.

02

Choose POST

When a user submits information for the server to process, such as sending a message or creating an account.

In conclusion, GET and POST serve different purposes. Choosing the correct method helps make web applications clearer and more predictable.
